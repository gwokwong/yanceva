## 篇 2【知乎】为什么我认为"AI 沙盘推演"会吃掉一小块传统市场调研的蛋糕

**目标人群**：创业者/产品经理/调研从业者 · **配套服务**：① 全部服务（方法论铺垫）

**正文**：

先说结论：我不是来吹 AI 万能的。传统调研的样本真实性和统计效力，AI 沙盘比不了。

但有两个场景，AI 沙盘的成本优势是碾压级的：

**场景一：上市前的"差评预演"。** 传统 focus group 一场 2-5 万，周期 2 周。而新品上市最大的风险——价格锚点错位、卖点自嗨、竞品截流——恰恰是可以在模拟市场里暴露的。我们把新品放进一个由虚拟消费者、KOL、竞品、媒体组成的社交环境里推演 48 小时，输出的是带量化指标（声量/情绪/购买意愿）和角色原话的报告，成本几十美元。

**场景二：应对策略的 A/B 重放。** 竞品降价了，你该跟价还是发对比稿？真实世界你只能选一次。沙盘里可以跑两遍——同样的用户画像，不同应对策略，看哪个方案的流失更少。这是传统调研根本做不到的。

**它的局限也要说清楚**：模拟 Agent 是 LLM 生成的虚构角色，反映的是"某一类人的典型反应"，不是统计样本；结论用于发现问题、比较方案，不能当预测承诺。

我们的实现基于多智能体框架（Graphiti 知识图谱 + OASIS 双平台模拟 + 市场信号提取），全链路开源可自查。

欢迎理性讨论：你觉得 AI 调研的边界在哪里？

## 篇 6【知乎】Notion 涨价那天，如果你的 SaaS 也想涨价——先看看沙盘里会发生什么

**目标人群**：SaaS 创始人/独立开发者 · **配套服务**：② SaaS 定价/改版沙盘

**正文**：

每次有 SaaS 涨价，HN/Reddit 上都是一场大型翻车现场直播。Notion、Figma、 Zapier 都交过学费。

涨价的坑不是"涨多少"，而是：
1. **哪个群体最先流失**（免费用户？个人付费？团队客户？）
2. **替代品会被竞品推多远**（你涨价的当天就是竞品截流的最佳时机）
3. **社区舆论走向**（HN 帖子是"合理调整"还是"greedy"）

我们做了一个沙盘：60 个虚拟角色——在用用户、流失用户、独立开发者社区 KOL、科技媒体、竞品——推演定价调整后 72 小时的社区反应。你能看到：
- 明确表示 cancel/migrate 的声音比例与迁移去向
- 哪个定价档位呼声最高
- 竞品截流帖的实际效果

还可以重放：$12→$15 和 $12→$18 各跑一遍，流失曲线一对比就清楚了。

诚实声明：模拟角色是 LLM 生成的典型画像，不是你的真实用户数据。但它能在真实涨价前，给你一份"最愤怒的用户会说什么"的预演报告。

## 篇 9【即刻/V2EX】Build in Public：我用开源多智能体引擎做了一个"市场沙盘"SaaS

**目标人群**：开发者/技术社区 · **配套服务**：平台整体（技术向引流）

**正文**：

分享一下我最近两个月 build in public 的东西：一个多智能体市场预演平台。

技术栈说下：
- 引擎：MiroFish（开源多智能体预测引擎，Flask + Vue），改造点是把硬编码的舆情场景抽象成了场景注册表
- 图谱：graphiti 0.11.6 + Neo4j（被 camel-oasis 的 neo4j==5.23.0 钉死了版本，等上游解开）
- 模拟：OASIS 双平台（Twitter/Reddit 风格）子进程 + 文件 IPC
- LLM：DeepSeek API（写了个兼容层处理它模仿 JSON Schema 返回 properties 包装的问题，妙）
- Embedding：本地 Ollama + Qwen3-Embedding-0.6B（服务器没显卡，0.6B CPU 完全够）
- 支付：Creem（MoR，个人可接，支付宝提现人民币）
- 订单系统：SQLite(WAL) 起步 + Worker 认领模式，跨机等 MinIO+PG

踩的坑值得单独开帖：
1. 所有实体都会变 Agent——电商场景里"产品"也会开口说话，做了知识节点过滤
2. 模拟结束后 OASIS 子进程停在等待命令模式不退出，runner 永远不到 COMPLETED——worker 里自动发 close_env
3. DeepSeek 会模仿 prompt 里的 JSON Schema 结构返回 properties 包装——兼容层递归解包

架构上最满意的决定：场景注册表。每加一个服务 = 一个场景包 + 一行 SKU，平台代码零改动。现在 6 个场景全在跑。

开源引擎在 GitHub（MiroFish），欢迎 star。产品地址见评论区。
